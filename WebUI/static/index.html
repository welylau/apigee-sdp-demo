Apigee X + Sensitive Data Protection (SDP) Architecture

Enterprise Defense-in-Depth
STEP 1
Verify the app

Apigee checks the API key, spike arrest and the per-app LLM token quota.

STEP 2
Mask the prompt

Every text part goes to SDP in one content:deidentify call (inspect-sensitive-v2). Only tokens reach gemini-3.5-flash-lite. Fails closed.

STEP 3
Mask the answer

Outbound SDP catches PII the model invents or rebuilds before the client sees it.
