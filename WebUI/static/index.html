Apigee X + Sensitive Data Protection (SDP) Architecture

Enterprise Defense-in-Depth
STEP 01
Client Prompt Ingress

The app calls Apigee with its API key. Apigee enforces spike arrest and an LLM token quota per app.

STEP 02
Inbound SDP De-identification

Every text part (system instruction and all turns) goes to SDP in one content:deidentify call (inspect-sensitive-v2). Findings become infoType tokens. Fails closed.

STEP 03
Cloud Logging Audit

Apigee writes a structured, sanitized audit entry to projects/YOUR_GCP_PROJECT_ID/logs/apigee-sdp-logs.

STEP 04
Vertex AI Gemini

Only sanitized text reaches gemini-3.5-flash-lite on the Vertex AI global endpoint.

STEP 05
Outbound SDP Scan

Apigee de-identifies every candidate in the model response, including anything the model invented, before returning it.
